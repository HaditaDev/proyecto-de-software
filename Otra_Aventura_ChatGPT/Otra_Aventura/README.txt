# Otra Aventura

Sitio web estático de promoción turística.

## Tecnologías
- HTML5
- CSS3
- Media queries para responsive
- PDF para itinerarios descargables
- PNG locales para imágenes representativas

No contiene JavaScript.

## Estructura
- index.html
- destinos.html
- playa.html
- montana.html
- contacto.html
- quien-mantiene.html
- estilosIA.css
- imagenes/
- guias/

## Nota
Las imágenes PNG incluidas son ilustraciones originales generadas localmente para representar cada destino.
